# Learn SOC With Me - Series Roadmap

This file keeps the series consistent across future labs.

## Series Promise

Each lab should be:

- Safe and synthetic
- Beginner-friendly
- Evidence-based
- Mapped to MITRE ATT&CK where appropriate
- Built with a report template
- Published as a static GitHub Pages lab

## Labs

| Lab | Topic | Primary Skill |
|---|---|---|
| 01 | Password Spray Investigation | Identity triage |
| 02 | Suspicious PowerShell | Endpoint investigation |
| 03 | Phishing Login | Email and identity correlation |
| 04 | New Local Admin User | Windows privilege escalation |

| 06 | Cloud IAM Anomaly | Cloud identity and privilege triage |
