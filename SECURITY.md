# Security Policy

## Defensive Training Only

This repository contains a synthetic SOC investigation lab. All users, apps, domains, IP addresses, files, tokens, permissions, and logs are fictional or reserved for documentation and training.

Do not use this repository to test against real tenants, real users, real OAuth apps, or real cloud services without explicit written authorization.

## Reporting Issues

If you find a problem in the lab content, such as unsafe wording, accidental real-world indicators, broken detections, or incorrect ATT&CK mapping, open a GitHub issue with:

- The affected file
- The specific concern
- The recommended correction

## No Secrets

Never add real credentials, tokens, tenant IDs, customer names, private domains, or real incident data to this repository.
